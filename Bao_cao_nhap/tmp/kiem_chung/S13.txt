                                                                                        following:

                                                                                        1) For multi-branch AC arc fault detection, the load addition process
                                                                                           would change the time-frequency characteristics of the current loop,
                                                                                           which is easy to lead to the arc fault detection maloperation. The
                                                                                           ICEEMDAN algorithm is used to reduce the residual noise in the
                                                                                           signal analysis process by adding the Gaussian noise with the adap­
                                                                                           tive amplitude. The optimal combination of detection variables is
                                                                                           constructed and selected by applying the Boruta algorithm. The arc
                                                                                           fault detection algorithm based on the LightGBM algorithm realizes
                                                                                           the high-precision arc fault detection by constructing a histogram
                                                                                           and using the leaf-wise strategy.
                                                                                        2) Two evaluation indexes, Q1 and Q2, are constructed to quantitatively
                                                                                           evaluate the detection variable performance. Q1,IC is reduced to
                                                                                           0.447 times on average of Q1,WT and Q2,IC is increased to 8.47 times
                                                                                           on average of Q2,WT. The ability of the ICEEMDAN algorithm is
Fig. 15. Arc fault detection results for the fluorescent lamp on the Raspberry pi
                                                                                           verified to distinguish arc faults from the load addition process.
platform (multi-branch).                                                                   When the arc fault occurs in system configuration B, the extracted arc
                                                                                           fault information is less, which is more likely to cause the detection
                                                                                           difficulty. In this case, the proposed algorithm could still sufficiently
                                                                                           extract the obvious arc fault information.
                                                                                        3) The Boruta algorithm is used to further reduce the feature di­
                                                                                           mensions, simplifying the calculation of the algorithm. The
                                                                                           LightGBM algorithm is used to reduce the memory occupation of the
                                                                                           algorithm and improves the operation speed of the algorithm. Based
