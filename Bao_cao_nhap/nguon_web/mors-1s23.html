1S23

General information

SKU
1S23
Short Description
ARC Fault Interface Module
Long Description

Working with a third-party protection relay, the 1S23 adds arc fault coverage to a protection scheme. It monitors one or two 1S30 optical sensors to detect arcing faults within metal-clad air-insulated switchgear. Housed in a compact DIN-rail package, it provides M4 screw terminals for the optical sensors and auxiliary supply. The 1S23 delivers an arc fault trip output and continuously supervises the sensor for maximum availability. Interface wiring uses 2m colour-coded flying leads: blue for the arc fault trip output and white for the supervision status output. Refer to the 1S30 bulletin for sensor details.

Quantity

Features

  • High speed sensing and operation
  • Designed to interface with protection relay status
  • Continuous arc fault sensor supervision
  • Arc fault pick up and supervision healthy
  • Simple wiring and DIN rail mounting
  • Compact, simple, rugged and economic design
  • 24, 32, 48, 110, 125, 220, 240 and 250V DC
  • 10 to +55 degrees Celsius

Application

For new installations or simple retrofits, the 1S23 interfaces with the binary inputs of existing protection relays that trip a circuit breaker. Arc fault protection can be implemented on an arc-only basis, or enhanced with a current check using protection relay logic and a fast instantaneous overcurrent element. The relay used should have programmable AND-gate logic, high-speed status inputs (<5 ms), a high-speed current check (<15 ms at 2× setting) and programmable indication.
